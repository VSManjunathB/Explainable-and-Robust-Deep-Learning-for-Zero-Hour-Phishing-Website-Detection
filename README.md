# Explainable & Robust Deep Learning Framework for Zero-Hour Phishing Website Detection 🔐

📊 Explainable & Robust Deep Learning Framework for Zero-Hour Phishing Website Detection

This project presents a comprehensive study on phishing website detection using deep learning techniques combined with Explainable Artificial Intelligence (XAI). The study focuses on developing a robust and interpretable model capable of detecting zero-hour phishing attacks using structured website and URL-based features.

---

🚀 Project Overview:

Phishing websites are a major cybersecurity threat designed to mimic legitimate platforms and steal sensitive information. Traditional detection systems struggle to identify newly created (zero-hour) phishing websites.

This project aims to explore how deep learning models can be used to detect phishing websites while ensuring model interpretability using XAI techniques such as SHAP and LIME.

---

📥 Dataset Information

Dataset Type: Phishing Website Dataset
Features Used: URL-based features, lexical features, host-based features, and webpage-related attributes
Source: Public cybersecurity datasets
Purpose: Classification of phishing vs legitimate websites

---

🧹 Data Preprocessing

The dataset was prepared using the following steps:

Handling missing values
Removing duplicate records
Feature transformation and encoding
Data normalization and scaling
Feature selection and engineering

---

📊 Exploratory Data Analysis (EDA)

EDA was performed to understand patterns in the dataset:

Feature distribution analysis
Correlation analysis between variables
Class imbalance visualization
URL structure analysis
Comparison of phishing and legitimate websites

---

🤖 Machine Learning Models

The project explores deep learning-based classification models:

Artificial Neural Networks (ANN)
Deep Neural Networks (DNN)
Hybrid feature-based models

These models are designed to learn complex patterns in phishing website data.

---

🧠 Explainable AI (XAI)

To improve interpretability, the following methods were used:

SHAP (SHapley Additive exPlanations)
LIME (Local Interpretable Model-agnostic Explanations)

These techniques explain model predictions and highlight important features influencing classification.
